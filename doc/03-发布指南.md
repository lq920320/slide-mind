# SlideMind 发布指南

> 面向维护者：如何签名、打包并发布一个新版本。

## 1. 发布流程概览

```
更新版本号 → git tag vX.Y.Z → push tag
  → GitHub Actions（release.yml）三平台构建
  → 生成 Release 草稿（安装包 + latest.json）
  → 人工检查后 Publish → 客户端自动收到更新提示
```

版本号需同步修改三处：`package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`。

> ⚠️ **首次建仓前必查**：`tauri.conf.json > plugins.updater.endpoints` 与 `release.yml`
> 当前假定仓库为 `github.com/lq920320/slide-mind`。
> 若实际仓库名不同，自动更新将整体失效，务必同步修改。

## 2. 必需的 GitHub Secrets

### 2.1 updater 签名（必需）

自动更新要求所有更新包带签名。密钥已在本地生成（`.tauri-keys/`，已 gitignore）：

| Secret                               | 内容                               |
| ------------------------------------ | ---------------------------------- |
| `TAURI_SIGNING_PRIVATE_KEY`          | `.tauri-keys/updater.key` 文件内容 |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 生成时的密码（当前为空字符串）     |

公钥已写入 `tauri.conf.json > plugins.updater.pubkey`。

⚠️ **私钥丢失将导致老用户永远收不到更新**，请离线备份 `.tauri-keys/updater.key`。

### 2.2 macOS 签名与公证（可选，推荐正式版配置）

| Secret                        | 内容                                              |
| ----------------------------- | ------------------------------------------------- |
| `APPLE_CERTIFICATE`           | Developer ID Application 证书（.p12 的 base64）   |
| `APPLE_CERTIFICATE_PASSWORD`  | .p12 密码                                         |
| `APPLE_SIGNING_IDENTITY`      | 如 `Developer ID Application: Your Name (TEAMID)` |
| `APPLE_ID` / `APPLE_PASSWORD` | Apple ID 与 App 专用密码（公证用）                |
| `APPLE_TEAM_ID`               | 团队 ID                                           |

未配置时产出未签名 dmg，用户需执行：
`sudo xattr -d com.apple.quarantine /Applications/SlideMind.app`

### 2.3 Windows 签名（可选）

如有代码签名证书，参考 [tauri-action 文档](https://github.com/tauri-apps/tauri-action) 配置
`WINDOWS_CERTIFICATE` / `WINDOWS_CERTIFICATE_PASSWORD`。

## 3. 自动更新机制

- 客户端启动时静默请求
  `https://github.com/lq920320/slide-mind/releases/latest/download/latest.json`
- `latest.json` 由 `tauri-action`（`includeUpdaterJson: true`）在发布时自动生成并上传
- 有新版本时弹窗询问，确认后下载安装并自动重启
- 无网络 / 无新版 / 校验失败均静默忽略，不打扰用户

## 4. 发布检查清单

- [ ] 三处版本号一致
- [ ] `pnpm lint && pnpm test && pnpm build` 全绿
- [ ] `cargo clippy && cargo test` 全绿
- [ ] 本地 `pnpm tauri build` 冒烟：安装包可安装启动，打开 `examples/` 示例文件正常
- [ ] 打 tag 推送，等待 Release 草稿生成
- [ ] 下载三平台产物抽查安装
- [ ] 编写 Release Notes 后 Publish
- [ ] 用旧版本客户端验证更新提示

## 5. 本地打包调试

```bash
pnpm tauri build                     # 当前平台安装包（src-tauri/target/release/bundle/）
pnpm tauri build --target aarch64-apple-darwin   # 指定目标
```

updater 产物本地验证需设置环境变量：

```bash
export TAURI_SIGNING_PRIVATE_KEY="$(cat .tauri-keys/updater.key)"
export TAURI_SIGNING_PRIVATE_KEY_PASSWORD=""
pnpm tauri build
```
